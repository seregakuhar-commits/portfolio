# NFC Business Card Landing — Design Spec

## Goal

Демо-лендинг для бизнеса на онлайн визитках и NFC-картах. Один статический файл `nfc-card/index.html`, весь CSS и JS inline, без CDN-зависимостей. Добавляется в портфолио на GitHub Pages.

## Architecture

Единый `index.html` с inline CSS и JS. Структура аналогична другим демо в портфолио (`beauty-salon`, `admin`). Никаких сборщиков, никаких внешних запросов.

## Tech Stack

- HTML5, CSS3 (custom properties, grid, flexbox, CSS transitions)
- Vanilla JS (переключатель тарифов, анимация шагов)
- Нет CDN, нет npm, нет фреймворков

## Sections

### 1. Hero

Двухколоночный layout (`grid: 1fr 1fr`, gap 60px). На мобиле — одна колонка.

**Левая колонка:**
- Бейдж: «NFC · QR · Digital» (строчка с золотыми точками)
- `<h1>`: «Ваша визитка —<br>одно касание»
- `<p>`: «NFC-карточка + цифровая визитка. Поделись контактами за секунду — без приложений»
- Кнопка «Заказать карточку» — золотой фон `#c9a84c`, тёмный текст, `border-radius: 8px`
- Под кнопкой: «от 990 ₽ · доставка 3-5 дней» мелким muted-текстом

**Правая колонка — живая демо-визитка:**

CSS-карточка, имитирующая физическую NFC-карту (соотношение сторон `85.6mm × 54mm` → примерно `340px × 215px`).

```
┌─────────────────────────────────┐
│  ░░░░ [логотип-инициалы]        │  ← золотой квадрат с буквами
│                                 │
│  Александр Соколов              │  ← имя, крупно, белый
│  Основатель · TechStart         │  ← должность, muted
│                                 │
│  ✆ +7 999 123-45-67             │  ← иконка + телефон
│  ✉ alex@techstart.ru            │  ← иконка + email
│  🔗 techstart.ru                │  ← иконка + сайт
│                                 │
│  [in] [tg] [wa]                 │  ← иконки соцсетей (SVG inline)
│                         [NFC ≋] │  ← NFC символ справа внизу

```

Фон карточки: `linear-gradient(135deg, #1a1a2e, #0d0d1a)`.
Рамка: `1px solid rgba(201,168,76,0.3)`.
Hover: `box-shadow: 0 20px 60px rgba(201,168,76,0.15)`, лёгкий подъём `translateY(-4px)`.
Transition: `0.3s ease`.

### 2. Как это работает

Заголовок секции: «Три шага до первого касания»

3 шага горизонтально (`grid: repeat(3, 1fr)`). Между шагами — стрелка `→` (muted цвет).

Каждый шаг:
- Круг с золотым номером (1 / 2 / 3), `48px`, border `2px solid #c9a84c`
- Заголовок (белый, `font-weight: 700`)
- Описание (muted)

| # | Заголовок | Описание |
|---|---|---|
| 1 | Заказываешь карточку | Выбираешь физический дизайн карточки. Доставим за 3-5 дней |
| 2 | Настраиваешь визитку | Заполняешь имя, контакты, соцсети в личном кабинете |
| 3 | Делишься одним касанием | Прикладываешь телефон — контакты мгновенно переданы |

---

### 3. Возможности

Заголовок: «Всё что нужно — уже внутри»

6 карточек `3×2` (`grid: repeat(3, 1fr)`). На мобиле `2×3`.

Каждая карточка:
- Фон: `--surface` (`#1a1a2e`)
- Рамка: `1px solid --border`
- Inline SVG-иконка (24×24, stroke gold)
- Заголовок (белый)
- Описание (muted, `font-size: 0.875rem`)

| Иконка | Заголовок | Описание |
|---|---|---|
| wifi / nfc | NFC + QR в одной карточке | Работает с любым телефоном — через касание или сканирование |
| edit | Редактируй в любой момент | Сменил номер или должность — обнови визитку без замены карточки |
| bar-chart | Статистика просмотров | Видишь кто и когда открыл твою визитку |
| palette | Любой дизайн | Цвета, логотип, фото — под твой бренд |
| smartphone | Без приложений | Получатель просто видит страницу — ничего устанавливать не нужно |
| leaf | Без бумаги | Одна NFC-карточка заменяет сотни бумажных визиток |

SVG-иконки: простые stroke-иконки, нарисованные inline (не CDN). Стиль совпадает с иконками в `admin/index.html`.

## JS Behaviour

Только два блока JS:

1. **Sticky nav highlight** — `IntersectionObserver` на секциях, активная ссылка подсвечивается золотом
2. **Smooth scroll** — `document.querySelectorAll('a[href^="#"]')` + `scrollIntoView({ behavior: 'smooth' })`

Никаких сложных интерактивных элементов — карточка уже достаточно впечатляет визуально.
