# Admin Panel Demo — Design Spec

**Date:** 2026-06-04  
**Status:** Approved

---

## Goal

Создать демо «Админ-панель» для портфолио — статический одностраничный HTML-файл без зависимостей, демонстрирующий навык верстки CRM-интерфейсов.

---

## Constraints

- Один файл: `admin/index.html`
- Весь CSS и JS инлайн (нет внешних ресурсов)
- Нет зависимостей: нет npm, нет CDN-библиотек
- Все данные — мок (статические массивы JS)
- Поддержка современных браузеров (Chrome/Edge/Firefox latest)

---

## Layout

**Структура (выбор В — Топ-бар + иконки):**

```
┌────────────────────────────────────────┐
│  Topbar (40px) — лого, поиск, аватар   │
├───────┬────────────────────────────────┤
│ Icon  │                                │
│ Side  │     Main content area          │
│ bar   │     (меняется при навигации)   │
│ 48px  │                                │
│       │                                │
└───────┴────────────────────────────────┘
```

- **Topbar:** высота 40px, белый фон, логотип слева («AdminPro»), поисковая строка по центру, аватар-аббревиатура справа
- **Icon sidebar:** ширина 48px, 5 иконок навигации, активная иконка выделена navy-цветом, тултипы при hover
- **Main content:** `padding: 24px`, меняется JS'ом при клике на иконку сайдбара

## Navigation & Sections

Клик на иконку сайдбара скрывает текущий раздел и показывает новый (CSS `display: none / block` + JS).

| # | Иконка SVG | Раздел | URL-хэш |
|---|---|---|---|
| 1 | grid (4 квадрата) | Dashboard | `#dashboard` |
| 2 | shopping-bag | Заказы | `#orders` |
| 3 | box | Товары | `#products` |
| 4 | users | Клиенты | `#clients` |
| 5 | settings (шестерня) | Настройки | `#settings` |

При загрузке страницы — активен «Dashboard».

---

## Sections Detail

### 1. Dashboard

Четыре stat-карточки в ряд (`grid-template-columns: repeat(4, 1fr)`):

| Карточка | Значение | Иконка | Цвет иконки |
|---|---|---|---|
| Заказы | 1 284 | shopping-bag | orange |
| Выручка | 284 500 ₽ | trending-up | green |
| Клиенты | 3 741 | users | navy |
| Конверсия | 4.2% | percent | purple |

Каждая карточка: белый фон, `border-top: 3px solid var(--orange)`, тень, значение крупным шрифтом (28px bold), лейбл под ним (14px muted), иконка справа.

Под карточками — CSS-гистограмма «Активность за 7 дней» (7 столбцов, высота из inline `style`), и таблица «Последние заказы» (5 строк, колонки: №, Клиент, Сумма, Статус, Дата).

### 2. Заказы

Таблица 10 строк с моковыми данными. Над таблицей — три кнопки-фильтра: «Все», «Новые», «Выполненные», «Отменённые». Клик фильтрует строки таблицы JS'ом (toggle `display`).

Колонки: №, Клиент, Товар, Сумма, Статус (бейдж), Дата.

Статус-бейджи: Новый (orange), Выполнен (green), Отменён (red) — CSS-классы `.badge-new`, `.badge-done`, `.badge-cancel`.

### 3. Товары

Сетка 3 колонки (`grid-template-columns: repeat(3, 1fr)`), 6 карточек товаров.

Каждая карточка: placeholder-изображение (CSS-прямоугольник с bg-цветом), название, цена (bold orange), кнопки «Редактировать» и «Удалить» (визуальные, без action).

### 4. Клиенты

Таблица 8 строк.

Колонки: Аватар (круг с аббревиатурой), Имя, Email, Телефон, Дата регистрации, Статус (Активен / Неактивен).

### 5. Настройки

Форма в карточке (max-width: 520px).

Поля: Название магазина (text), Email уведомлений (email), Валюта (select: ₽ / $ / €), Язык (select: Русский / English), Уведомления о заказах (checkbox), Кнопка «Сохранить изменения» (navy, hover orange).

---

## Animations

- Fade-in при смене раздела: `opacity 0→1, translateY(8px→0), duration 200ms ease`
- Hover на строках таблицы: `background: #f9fafb`
- Hover на кнопках: `opacity: 0.85` или смена фона

---

## Interactivity (pure JS)

1. **Navigation:** клик по иконке сайдбара — меняет `data-active` секцию, подсвечивает иконку
2. **Order filter:** кнопки фильтра добавляют/убирают `display:none` на `<tr>` по data-status
3. **Settings form:** кнопка «Сохранить» показывает inline-уведомление «Настройки сохранены ✓» на 2 секунды (тост в углу)
