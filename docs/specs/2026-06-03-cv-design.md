## Макет

Двухколоночный: фиксированный сайдбар 280px слева + гибкий основной контент справа.

```
┌──────────────┬─────────────────────────────┐
│   САЙДБАР    │      ОСНОВНОЙ КОНТЕНТ        │
│   280px      │      flex: 1                 │
│              │                              │
│ • Аватар     │ • О себе                     │
│ • Имя        │ • Опыт (таймлайн)            │
│ • Должность  │ • Образование                │
│ • Контакты   │ • Проекты (карточки)         │
│ • Навыки     │                              │
│ • Языки      │                              │
└──────────────┴─────────────────────────────┘
```

**Адаптив (≤700px):** сайдбар встаёт сверху, основной контент снизу (flex-direction: column).

## Анимация

Те же `.reveal` + `IntersectionObserver` что в beauty-salon:
- Класс `reveal` на: секции "О себе", "Опыт", "Образование", "Проекты"
- При 15% видимости — `opacity: 0 → 1` + `translateY(30px → 0)` за 0.6s
- `observer.unobserve` после срабатывания — без повторов
