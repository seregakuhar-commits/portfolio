# NFC·Card — Лендинг шаблон

Готовый лендинг для продажи NFC-визиток. Один HTML-файл, всё внутри — CSS и JS уже встроены. Никаких сборщиков, никаких зависимостей.

---

## Что входит в пакет

| Файл | Описание |
|---|---|
| `index.html` | Готовый лендинг (весь код внутри) |
| `ИНСТРУКЦИЯ.md` | Этот файл |

---

## Как запустить

Просто откройте `index.html` в любом браузере — всё работает без сервера и интернета.

---

## Как разместить в интернете

**GitHub Pages (бесплатно):**
1. Создайте репозиторий на github.com
2. Загрузите `index.html`
3. Перейдите в Settings → Pages → Source: main branch
4. Сайт будет доступен по адресу `https://username.github.io/repo-name`

**Обычный хостинг:**
- Загрузите `index.html` в корневую папку хостинга через FTP или панель управления

Найдите `https://t.me/YOURUSERNAME` и замените на вашу ссылку:

## Как изменить цвета

В начале файла, в блоке `:root { ... }`, найдите:

```css
/* ✏️ ИЗМЕНИТЬ: основные цвета */
--bg: #0f0f1a;        /* цвет фона (тёмно-синий) */
--surface: #1a1a2e;   /* цвет карточек и секций */
--gold: #c9a84c;      /* акцентный золотой цвет */
--gold-light: #f5d78e; /* светлый золотой (для градиентов) */
```

Меняйте `--gold` на любой акцентный цвет под ваш бренд.

## Часто задаваемые вопросы

**Нужен ли сервер для запуска?**
Нет. Открываете файл локально — работает.

**Можно ли изменить количество тарифов?**
Да. Просто скопируйте или удалите блок `<div class="pricing-card">`.

**Как добавить форму заказа?**
Самый простой способ — сделать кнопки ссылками на Telegram/WhatsApp. Для полноценной формы можно использовать сервисы Formspree или Tally (вставить их iframe).

**Можно ли использовать другой язык?**
Да — просто замените все русские тексты на нужный язык.
