# Чек-лист поставки лендинга клиенту

Проходить сверху вниз при каждой продаже. Ничего не пропускать —
клиент заметит именно то, что пропустил.

## 1. Подготовка (до начала работы)

- [ ] Получить от клиента: тексты, цены, телефон, адрес, режим работы, логотип (если есть)
- [ ] Получить фото (его объекты/работы/интерьер). Нет фото — согласовать стоковые и скачать их к себе (не хотлинк)
- [ ] Узнать, куда должны приходить заявки: Telegram / email / телефон
- [ ] Узнать, есть ли домен и хостинг. Нет — предложить настройку (отдельная строка в смете)
- [ ] Скопировать папку лендинга в отдельный проект клиента (исходник в портфолио не трогать!)

## 2. Контент

- [ ] Заменить все тексты: название, заголовки, описания услуг, цены
- [ ] Заменить телефон, email, адрес, режим работы (поиском по файлу: `123-45-67`, `info@`, `ул.`)
- [ ] Заменить все фото, прописать осмысленные `alt`
- [ ] Убрать футер «Демо-проект · ← Портфолио»
- [ ] Проверить, что не осталось слов «Демо», «СтройМастер», «Studio Noir» и прочих заглушек: `Ctrl+F` по каждому файлу

## 3. Ссылки и контакты

- [ ] Все ссылки `t.me/SeregaKuhar` → контакт клиента
- [ ] Кнопки соцсетей → реальные страницы клиента (лишние удалить)
- [ ] Проверить каждую ссылку кликом

## 4. Форма заявки

- [ ] Подключить реальную отправку (Telegram-бот / Formspree / почта) — см. комментарий в JS «Здесь подключается отправка»
- [ ] Отправить тестовую заявку и убедиться, что она дошла
- [ ] Добавить чекбокс «Согласен на обработку персональных данных» + страницу политики конфиденциальности (152-ФЗ)

## 5. Мета и SEO

- [ ] `<title>` и `<meta name="description">` — под бизнес клиента
- [ ] `<link rel="canonical">` и `og:image` — на домен клиента
- [ ] Перегенерировать og-image под бренд клиента (1200×630)
- [ ] Favicon под бренд клиента
- [ ] Если несколько страниц — обновить sitemap.xml и robots.txt под домен клиента

## 6. Проверка перед сдачей

- [ ] Открыть с телефона: меню, формы, кнопки, скролл
- [ ] Проверить в Chrome и в другом браузере (Firefox/Safari)
- [ ] Прогнать через PageSpeed Insights (pagespeed.web.dev) — должно быть зелёное
- [ ] Валидатор HTML: validator.w3.org — без ошибок
- [ ] Кликнуть каждую кнопку и ссылку ещё раз

## 7. Деплой и сдача

- [ ] Выложить на хостинг/домен клиента (или GitHub Pages + домен)
- [ ] Проверить сайт на реальном домене (https работает, картинки грузятся)
- [ ] Поставить Яндекс.Метрику, дать клиенту доступ
- [ ] Отправить клиенту ссылку + короткую инструкцию: как смотреть заявки, как смотреть статистику
- [ ] Взять отзыв и разрешение добавить работу в портфолио
